# Lab 01 — Bancada digital e portas AND, OR e NOT

## Objetivos

- Identificar pinagem e alimentação de circuitos integrados da série 74HC.
- Medir as tensões que representam os níveis lógicos 0 e 1.
- Levantar experimentalmente a tabela da verdade das portas AND, OR e NOT.
- Implementar um circuito lógico a partir de uma função lógica.

## Procedimento

### Parte A — Níveis lógicos

1. Com a fonte desligada, insira o 74HC08 na matriz de contatos. Ligue o pino 14 a +5 V e o pino 7 a GND.
2. Ligue a fonte e meça a tensão de alimentação entre os pinos 14 e 7.
3. Meça a tensão de uma chave lógica nas posições 0 e 1.

| Grandeza                  | Valor medido (V) |
| :------------------------ | :--------------: |
| Tensão de alimentação VCC |                  |
| Chave em nível 0          |                  |
| Chave em nível 1          |                  |

### Parte B — Tabelas da verdade

Ligue as chaves A e B às entradas de uma porta (pinos 1 e 2) e a saída (pino 3) a um LED. Para cada combinação, anote o estado do LED e a tensão de saída. Repita para o 74HC32 e, com uma única chave, para o 74HC04 (entrada no pino 1, saída no pino 2).

|  A  |  B  | AND: Y | AND: Vo (V) | OR: Y | OR: Vo (V) |
| :-: | :-: | :----: | :---------: | :---: | :--------: |
|  0  |  0  |        |             |       |            |
|  0  |  1  |        |             |       |            |
|  1  |  0  |        |             |       |            |
|  1  |  1  |        |             |       |            |

|  A  | NOT: Y | NOT: Vo (V) |
| :-: | :----: | :---------: |
|  0  |        |             |
|  1  |        |             |

### Parte D — Entrada aberta

1. No 74HC08, mantenha a entrada A em nível 1 e **desconecte** o fio da entrada B. Observe a saída e meça a tensão no pino desconectado.
2. Ligue a entrada B a GND por um resistor de 10 kΩ (_pull-down_) e a +5 V por uma chave. Verifique que a entrada passa a ter nível definido nas duas posições da chave.

:::warning

Em CIs CMOS (série 74HC) uma entrada aberta **não tem nível definido**: o simulador mostra um valor qualquer e, no circuito real, a saída oscila com ruído e o consumo aumenta. Nenhuma entrada pode ficar aberta, nem as das portas não utilizadas.

:::

## Questões

1. As tensões medidas para os níveis 0 e 1 estão dentro das faixas válidas da família 74HC alimentada em 5 V? Compare com a folha de dados.
2. Como obter uma porta AND de 3 entradas usando apenas portas AND de 2 entradas? Desenhe o circuito.
3. Na Parte D, que valor lógico a porta "enxergou" na entrada aberta? Explique a função do resistor de _pull-down_ e por que ele não impede a chave de impor o nível 1.
4. Quantas linhas tem a tabela da verdade de um circuito com 5 entradas? Generalize para $n$ entradas.
5. Cite uma aplicação cotidiana que possa ser descrita pela função da Parte C.
