# Lab 04 — Soma de produtos e produto de somas

## Objetivos

- Obter expressões canônicas em soma de produtos (mintermos) e produto de somas (maxtermos) a partir da tabela da verdade.
- Implementar a mesma função nas duas formas e comprovar a equivalência.
- Implementar uma soma de produtos com dois níveis de portas NAND.

## Problema 1 — Circuito de votação

Três jurados (A, B e C) votam por meio de chaves (1 = aprovado). A lâmpada M deve acender quando a **maioria** aprovar.

| Linha |  C  |  B  |  A  | M previsto | M (SOP) | M (POS) |
| :---: | :-: | :-: | :-: | :--------: | :-----: | :-----: |
|   0   |  0  |  0  |  0  |            |         |         |
|   1   |  0  |  0  |  1  |            |         |         |
|   2   |  0  |  1  |  0  |            |         |         |
|   3   |  0  |  1  |  1  |            |         |         |
|   4   |  1  |  0  |  0  |            |         |         |
|   5   |  1  |  0  |  1  |            |         |         |
|   6   |  1  |  1  |  0  |            |         |         |
|   7   |  1  |  1  |  1  |            |         |         |

## Pré-laboratório

1. Preencha a coluna **M previsto**.
2. Escreva a expressão canônica em soma de produtos, na forma $M = \sum m(\ldots)$, e em produto de somas, na forma $M = \prod M(\ldots)$.
3. Simplifique algebricamente as duas expressões e mostre que resultam em:
   - $M = A \cdot B + A \cdot C + B \cdot C$
   - $M = (A + B) \cdot (A + C) \cdot (B + C)$
4. Quantas portas seriam necessárias para montar a soma de produtos **canônica**, sem simplificar?
5. Faça a tabela da verdade do Problema 2.

## Questões

1. Mostre, com De Morgan, que o circuito NAND-NAND da Parte A equivale à forma AND-OR.
2. Compare as implementações SOP e POS do circuito de votação quanto ao número de portas e de CIs.
3. Em que tipo de tabela da verdade a forma em produto de somas tende a ser mais econômica que a soma de produtos?
4. A expressão canônica da paridade pôde ser simplificada algebricamente em termos AND-OR? O que isso indica sobre funções do tipo XOR?
5. Projete (apenas no papel) o circuito de votação para 4 jurados, em que o empate reprova.
